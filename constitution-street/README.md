# Constitution Street, Aberdeen — project site

Two finished two-bedroom flats (19A and 19B) on the first floor of 19 Constitution Street, Aberdeen AB24 5EU, by Fame Living.

| File | What it is |
|---|---|
| `page.html` | Page source. Edit this, then rebuild `index.html` with the wrap script. |
| `index.html` | The built page served at `/constitution-street/`. |
| `model.js` | Geometry traced from Fairhurst's structural first-floor plan 401918/OM1 (March 2026; not to scale): walls, windows, rooms, fittings, flats. Generated by `tools/model/model.py`. |
| `viewer3d.js` | The 3D building, floor and walk-through viewer (`window.CS3D`). Built by joining `tools/viewer-src/*.js` in order: head, prisms, build, fixfurn, tail, rest. |
| `availability.json` | Put `19A` or `19B` in `reserved` or `sold`. The site updates when this file is published. |
| `plans/` | Crops of the structural drawings (per flat, first floor, sections). |
| `img/` | Photos of the finished flats (September 2026) and the 3D front view. |
| `investor-pack.pdf` | Built from `tools/pack/pack.html` with `node tools/pack/mk.js`. |

**Prices:** set `price` in `CONFIG` at the top of the page script, e.g. `price:{1:120000,2:105000}` (1 = 19A, 2 = 19B). Leave `null` for "Price on request". Setting a price turns on the currency selector, yields and the hero "From" figure.
Estimated rents are in `RENT`. Sales email, phone, WhatsApp, booking link and form endpoint are in `CONFIG`.
Colours: plum `#2D2236` and brass `#C9A24D` (dark theme default; light theme via the shared `fl-theme` toggle).
